Install notes

macOS: open the DMG and drag Bubble Wrap into Applications. The build is not notarized yet, so if Gatekeeper blocks the first launch, right-click the app and choose Open.

Windows: run the installer, choose a folder, and launch from the Start menu. SmartScreen may ask you to confirm because the installer is not code-signed yet.

Homebrew (macOS)

brew trust jd4rider/bubble-wrap
brew install --cask jd4rider/bubble-wrap/bubble-wrap

Homebrew asks you to trust a third-party tap once before loading its cask.

PowerShell (Windows)

irm https://bubblewrapgame.online/install.ps1 | iex

The script downloads the installer, verifies its SHA-256, and runs it silently. Prefer to do it yourself? Run Bubble-Wrap-win-setup.exe /S. Winget manifests live in the repo for winget install --manifest.
